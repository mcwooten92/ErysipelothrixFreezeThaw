# ErysipelothrixFreezeThaw
Repository for R code and raw data associated with the manuscript "Does freeze–thaw tolerance help explain the dominance of an Erysipelothrix rhusiopathiae clone in Canadian Arctic muskoxen (Ovibos moschatus)?"

# Prerequisites
R and RStudio are necessary for running the R code. The following R packages are required: 
"beepr", "dplyr", "forcats", "ggplot2", "gratia", "MASS", "mgcv", "patchwork", "ragg", "readxl", "systemfonts", and "tidyr"
